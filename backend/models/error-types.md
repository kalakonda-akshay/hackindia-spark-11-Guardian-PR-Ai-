# Error Taxonomy

This file defines the shared error categories across the review system.

## Structural errors

- `missing.review.context`
- `unclear.scope`
- `repository.structure.unknown`
- `workflow.conflict`

## Data errors

- `insufficient.diff`
- `insufficient.evidence`
- `missing.coverage`
- `incomplete.trace`

## Agent errors

- `routing.conflict`
- `agent.timeout`
- `unsupported.vulnerability.claim`
- `conflicting.findings`
- `empty.report`

## Dependency errors

- `package.metadata.missing`
- `dependency.scope.unclear`
- `memory.source.unavailable`

## Evaluation errors

- `unsupported.pass`
- `inconclusive.review`
- `evaluation.gap`
