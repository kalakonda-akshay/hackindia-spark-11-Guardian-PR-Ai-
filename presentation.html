Deep-Dive

Agent Roles & Work Breakdown

🎯

1. Triage Agent (Priority & Scope)

Scans changed file paths to flag high-security risk targets (e.g. `auth.ts`, `db.js`, `.env`) and prioritizes execution scope.

🔍

2. Context Agent (Diff Extraction)

Extracts raw unified code diffs (`diff --git`), modified AST functions, commit history, and author metadata.

🔒

3. Security Agent (SAST Analysis)

Performs deep prompt audits using Gemini AI to detect OWASP Top 10 flaws, hardcoded secrets, SQLi, and XSS.

📦

4. Dependency Agent (Supply Chain CVEs)

Scans package manifests (`package.json`, `requirements.txt`) to identify vulnerable or outdated 3rd-party dependencies.

🧠

5. Memory Agent (Historical Flaws)

Cross-references historical session memory to check if similar security bugs were previously flagged or fixed.

📝

6. Reporter Agent (Report Synthesis)

Calculates the 0-100 overall Security Risk Score, formats line-by-line fix recommendations, and posts GitHub Markdown comments.

🗣️ Speaker Script: "Each agent has a single, strictly defined responsibility — from initial file triage to deep SAST scanning, dependency CVE lookup, and final report synthesis."
Zero-Trust Security

Cryptographic Integrity & Auth Architecture

🔑

HMAC SHA-256 Signature Verification

Calculates HMAC hashes over raw HTTP bodies using a shared secret to ensure webhooks originate exclusively from GitHub.

🎟️

Stateless JWT User Authentication

Issues 7-day signed JSON Web Tokens for API authorization, validated via `Authorization: Bearer` headers.

🧂

Password Salting & Bcrypt Hashing

Uses `bcryptjs` with 10 salt rounds before storing credentials to eliminate rainbow table attack risks.

🛡️

OWASP Top 10 SAST Engine

Detects SQL injections, Cross-Site Scripting (XSS), insecure deserialization, and plain secret exposures.

🗣️ Speaker Script: "Security is built into Mutagent itself. Webhooks are HMAC SHA-256 verified, user sessions use 7-day JWT tokens, and all passwords are salted and hashed with Bcrypt."

Technical Concepts

Technical Terms & Buzzwords Glossary

Autonomous AI micro-services communicating via an event-driven publish/subscribe message bus (`MessageBus`).

WebSockets & Bi-Directional Streaming

Auditing 3rd and 4th level indirect dependencies in `package.json` against known vulnerability registries.

Stale-While-Revalidate (SWR)

Data caching strategy via React Query that renders cached UI instantly while refetching updated data in the background.
